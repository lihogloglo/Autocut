# Buy the derush, build the documentary layer

No single tool automates the whole Lemmino/Fern-style pipeline (derush, citation-driven illustration and SFX) inside Premiere. What does exist is a mature first layer you can buy and a set of open building blocks that make the rest a realistic weekend-to-month build. For the derush, **FireCut's "Remove repetition" and AutoCut Repeat** already find repeated takes of the same sentence inside Premiere and keep one of them. Both delete the rejected takes, though, and **no Premiere tool surveyed colour-labels or keeps alternates**. Only DaVinci Resolve's IntelliScript keeps them, on extra tracks. For B-roll, half a dozen Premiere plugins match transcript keywords to Storyblocks or Pexels. **None follows the creator's own inline citation links**, so that stage is an open gap in the market. The only public blueprint is a research paper (Sima 1.0) that targets Resolve. For SFX, **Epidemic Sound is the most automation-ready source**: its Premiere plugin drafts and places SFX on the timeline, and its MCP server lets Claude Code search and download from the catalogue on a personal subscription. Semantic placement of doc-style cues (paper under document shots, keyboard under "she searched", a whoosh on each graphic transition) is still unbuilt. The glue for a custom pipeline is now solid. Premiere's UXP API is officially released with insert, overwrite, marker and transcript actions. Community MCP servers expose hundreds of timeline tools, including colour labels. FCP7 XML remains the most reliable offline route into Premiere. The practical answer is to buy FireCut or AutoCut and the Epidemic plugin now. Then build one Claude-orchestrated pipeline that writes a reviewable Premiere timeline: alternates kept and labelled, citation images harvested per paragraph, and SFX cues resolved against your own library, Epidemic and ElevenLabs.

## Premiere plugins catch repeated takes but throw the alternates away

Premiere itself has moved a long way without solving the core derush problem. Text-Based Editing (since 2023) lets you delete transcript text to cut and lets you search fillers across a sequence ([TechRadar](https://www.techradar.com/news/adobe-premiere-pro-update-lets-you-edit-videos-like-its-a-word-doc)). Media Intelligence (25.6 beta, then 26.x) runs on-device search for similar shots and alternate takes ([Adobe help](https://helpx.adobe.com/premiere-pro/using/media-intelligence-and-search-panel.html)). **Premiere 26.5 (September 2026) added Paper Edit**, which builds a sequence from transcript lines you highlight, and a new Voice Activity Detection transcription model ([Kyler Holland](https://www.kylerholland.com/blog/premiere-pro-september-2026-whats-new/)). None of these features detects "same sentence said three times, keep the best". Paper Edit still leaves the choice of take to you. Adobe's own framing of where alternate-take AI is heading concerns visual flaws like camera shake, not spoken repeats ([Adobe community](https://community.adobe.com/announcements-727/premiere-pro-v25-6-firefly-integration-smarter-search-and-more-1546583)).

Third-party tools fill that gap with varying fit.

| Tool | Where it runs | Repeated-take handling | What happens to alternates | Price (Nov 2026) |
|---|---|---|---|---|
| FireCut | Premiere panel (also Resolve) | Groups every take of a repeated phrase; you tick one; tunable phrase size, tolerance, search radius; docs say "the last take is usually the best" | Deleted | Pro $14/mo yearly ($23 monthly) |
| AutoCut Repeat | Premiere 2023–2026 panel (also Resolve) | Optional reference script, 80+ languages, claims to handle slight rephrasing, auto-selects "best" | Deleted after review | AI Plan $14.9/mo yearly |
| Gling | Standalone app, XML to Premiere (paid tiers) | "Remove bad takes" for YouTubers | Not documented | $10–50/mo yearly |
| Descript | Standalone, XML/AAF out | Underlord "Remove Retakes" picks "best, cleanest take" | Not documented | Conflicting reports, ~$16–65/mo |
| Cutback Auto Rough Cut | Premiere plugin plus Selects app | "Select the best takes", cut to script (Oct 17, 2026) | Not documented | Selects from $16/mo |
| Eddie AI | Cloud/desktop, XML or Premiere extension, MCP server | Interview rough cuts and soundbite selection | Not documented | ~500 credits/hour of footage ($10 per 1k) |
| Resolve 20 IntelliScript | Resolve only | Matches the transcript to the script | **Kept on extra tracks** | Studio $295 one-time |

Sources: [FireCut docs](https://learn.firecut.ai/features/remove-repetition.md), [FireCut pricing](https://firecut.ai/pricing), [AutoCut Repeat](https://www.autocut.com/autocutrepeat), [AutoCut pricing](https://www.autocut.com/pricing), [Gling pricing](https://gling.ai/pricing), [stigstack on Descript](https://stigstack.pages.dev/reviews/descript-review), [Cutback 2.35.0](https://cutback.video/blog/2-35-0-auto-rough-cut-open-mode-separation-and-pricing-updates), [CineD on Eddie](https://www.cined.com/eddie-ai-overhauled-pay-as-you-go-pricing-editing-from-claude-and-chatgpt-and-an-iphone-app/), [Engadget on IntelliScript](https://www.engadget.com/apps/davinci-resolve-20s-latest-ai-feature-can-create-an-entire-timeline-based-on-a-script-120009351.html).

For a 1–2 hour monologue recorded in one go, **FireCut is the closest fit to "keep the last good take"**. It groups takes per phrase, recommends the last one and exposes the parameters you would tune for partial restarts. AutoCut is the better pick if you script in French or another non-English language, since FireCut's repetition support outside English is experimental. Both still need a human pass, and FireCut occasionally clips word starts and ends. Nearly all comparison content is vendor-written, and independent sentiment calls these tools "an automated first pass rather than a creative cut" ([autoeditai](https://www.autoeditai.net/blog/autoedit-vs-autocut-vs-firecut-vs-autopod)). The deeper limitation for an essayist who wants to audition alternates later is structural. **Every Premiere plugin deletes the rejected takes, and none documents colour labels or markers for them.** Only Eddie AI exposes a programmatic interface (about 100 MCP tools). AutoCut, FireCut and Gling are GUI-only, so they cannot be scripted into a larger pipeline.

## Open-source derush is a kit of strong parts and young glue

The open-source silence layer is settled. **auto-editor (about 5.7k stars, pushed Oct 31 2026, public domain) is the only actively maintained silence cutter with a real Premiere export**, via `--export premiere` ([GitHub](https://github.com/WyattBlue/auto-editor)). It cuts on loudness with a configurable margin, so it cannot see retakes. carykh/jumpcutter and unsilence have been inactive for two to three years and render only video files ([GitHub API](https://api.github.com/repos/carykh/jumpcutter)).

Retake detection is where the action is, and it is all 2026-vintage and low-star. **retake-cutter** aligns your script to Whisper word timestamps with LCS and snaps repeated words to their last occurrence, so the corrected retake wins. It misses paraphrased retakes, runs in-browser on whisper-base and outputs only rendered video ([GitHub](https://github.com/gkavtaradze92/retake-cutter)). **OpenRoughCut** keeps the last attempt of restarted sentences using sentence similarity, has an optional Claude pass that judges by meaning, and exports **FCP7 XML, EDL and a JSON log of every cut with its reason**, plus an experimental UXP panel ([GitHub](https://github.com/victinjr199xs-cyber/openroughcut)). **OpenCut** offers CEP and UXP Premiere panels with VAD silence removal, CrisperWhisper filler detection and Jaccard-similarity "Repeated Take Detection". Crucially, it can apply cuts **as disabled clips rather than deletions**, which is the closest open-source behaviour to "keep alternates" ([GitHub](https://github.com/SysAdminDoc/OpenCut)). Ambar places orange review markers before committing cuts ([GitHub](https://github.com/Robelob/Ambar-AI-Video-Editor-Plugin-For-Premiere-Pro)). VoidCutter works on a sequence copy using Premiere's own transcript plus Gemini ([site](https://voidcutter.pages.dev/)). Rescript (about 1k stars) is a polished word-deletion editor with Premiere XML export, but it has no retake detection and carries a **non-commercial licence** ([GitHub](https://github.com/wassgha/rescript)). The most popular agent, **video-use (about 30k stars)**, has Claude Code read a packed transcript and decide cuts. It outputs MP4 plus EDL, not Premiere XML, and depends on ElevenLabs Scribe ([GitHub](https://github.com/browser-use/video-use)).

Two technical details decide whether a custom retake detector works. First, mid-sentence restarts ("so the — so the reason is") vanish if the ASR cleans them up. You need verbatim transcription. **CrisperWhisper keeps stutters and false starts with about 30–40 ms word-boundary error (self-reported), but its weights are non-commercial**, which matters for a monetised channel ([GitHub](https://github.com/nyrahealth/CrisperWhisper)). The commercial-safe alternative is WhisperX (BSD-2, about 25k stars) with a disfluent prompt ([GitHub](https://github.com/m-bain/whisperx)). Second, colour labels in FCP7 XML are shaky. Users report `<labels><label2>Forest</label2></labels>` inside a `<clipitem>` works, but **an Adobe community manager calls it unsupported** ([Adobe Community](https://community.adobe.com/t5/premiere-pro-discussions/using-xml-to-create-a-custom-label-color/m-p/12407852)), and other users report labels not surviving import. The reliable routes are markers (supported by OTIO's FCP adapter, and searchable by colour since Premiere 26.2) and the MCP servers' `set_color_label` tool applied after import (covered below). None of the open tools publishes accuracy figures on retake-heavy footage, so treat all of them as first passes.

## Citation-driven image harvesting is the gap nobody sells

Script-aware B-roll is crowded but generic. AutoCut AutoB-Rolls and FireCut "Find B-roll" read the transcript and drop Storyblocks or Pexels clips on the timeline. FireCut bundles the Storyblocks licence and can also AI-tag your own footage folder ([FireCut](https://firecut.ai/features/b-roll); [AutoCut blog](https://www.autocut.com/en/blogs/best-b-roll-plugin-premiere-pro/)). B-Roll Genie generates AI images from narration, and the official Storyblocks panel is search-only ([Storyblocks](https://www.storyblocks.com/plugin)). These help with atmospheric filler such as cityscapes, labs and money. They do not help with the photo of a named person, the scanned document or the 1970s newsreel your script cites. **No commercial product follows inline hyperlinks per paragraph to harvest images.** The closest public design is **Sima 1.0** (arXiv, April 2026). In it, a human annotates the script with insertion cues and source URLs, an asset agent downloads and transcodes, and parallel Claude Code "senior" agents place images and B-roll for 1–2 hour documentaries in DaVinci Resolve. Credits come from the URL comments ([arXiv](https://arxiv.org/html/2604.07721v1)). No code was released, and there is no Premiere output.

The open-source parts cover most of a build. louisedesadeleer/b-roll-finder is a Claude Code skill that routes each transcript beat to a source, searches YouTube via yt-dlp, screenshots pages with a headless browser and places cutaways on exact words ([GitHub](https://github.com/louisedesadeleer/b-roll-finder)). broll-fetcher takes a `scenes.json` and queries Pexels, Pixabay, Wikimedia and Openverse ([GitHub](https://github.com/Yashrout07/broll-fetcher)). ClipForage shows the licence on every result across YouTube, Internet Archive and Wikimedia ([GitHub](https://github.com/Ry0x7/ClipForage-source)). For the cited articles themselves, **newspaper4k extracts `top_image` and all article images** ([GitHub](https://www.github.com/AndyTheFactory/newspaper4k)), and og:image or srcset parsing recovers the largest version. Fork whatever you depend on, because one promising repo (erfsalehi/B-Roll-Finder) returned 404 during this research.

Three external constraints shape the design. **Google's Custom Search JSON API, including image search, shuts down on 1 January 2027** ([dev.to](https://dev.to/nexgendata/google-kills-custom-search-api-on-jan-1-2027-you-have-9-months-1jg1)), so "Google image search" has to go through a paid SERP provider. DataForSEO's Google Images API costs about $0.002 per page ([DataForSEO](https://dataforseo.com/apis/serp-api/google-images-api)), SerpApi starts at $75/month, and SerpApi's Google Lens API handles reverse search for higher-resolution originals ([SerpApi](https://serpapi.com/google-lens-api/release-notes)). **The YouTube Data API allows roughly 100 searches per day** (search.list costs 100 of 10,000 daily units) ([Google](https://developers.google.com/youtube/v3/getting-started)). That is why every hobby tool uses yt-dlp search, then searches captions for the timestamp and downloads only that section. Finally, rights matter more for this genre than for faceless shorts. A 4-second DMCA claim took Michael Moore's documentary off YouTube for two weeks ([IDA](https://documentary.org/online-feature/fair-use-documentary-never-ending-fight)). British Pathé's YouTube archive is not Creative Commons ([British Pathé](https://www.britishpathe.com/licensing/)). Internet Archive footage comes with no permission or indemnity ([Prelinger](https://www.panix.com/~footage/stockfootage.html)). The harvester should therefore record source page, author or agency, licence and resolution for every asset, and should prefer Wikimedia Commons and government sources when they exist.

### Blender and GeoLayers get agent hooks, not autopilots

For your own illustrations, **blender-mcp (MIT) lets Claude run arbitrary bpy, pull Poly Haven and Sketchfab assets and generate Hyper3D Rodin models** ([augmentcode](https://www.augmentcode.com/mcp/blender-mcp)). kleer001's variant offers 175 tested tools ([Glama](https://glama.ai/mcp/servers/kleer001/blender-mcp)). Blender was among Anthropic's April 2026 creative connectors ([AlternativeTo](https://alternativeto.net/news/2026/4/anthropic-launches-claude-connectors-for-adobe-blender-ableton-and-more/)). Meshy 6 has a dedicated Low Poly Mode, and Tripo's API generates low-poly meshes for roughly $0.30–0.40 per textured model in credits ([krea](https://www.krea.ai/blog/best-ai-3d-model-generators-2026); [layer.ai](https://layer.ai/models/tripo3d-v2-5.md)). Blosm and BlenderGIS import OSM buildings and terrain for map-like 3D scenes ([Blosm](https://github.com/vvoovv/blosm)). On the After Effects side, **AE has no UXP yet** and several ExtendScript MCP servers exist, such as Dakkshin/after-effects-mcp and kumoproductions/mcp-aftereffects ([kumoproductions](https://github.com/kumoproductions/mcp-aftereffects)). **No scripting API for GEOlayers 3 was found**, so automating maps means driving its effect properties from ExtendScript, which is unverified, or templating a master comp and swapping coordinates. Full GEOlayers styling also needs a MapTiler account ([aescripts](https://aescripts.com/geolayers/)). Google Earth Studio's keyframed AE camera export is a free complement for fly-overs ([lesterbanks](https://lesterbanks.com/?p=34203)). Realistically, an agent can draft scenes and map comps from a paragraph, but the look stays hand-tuned.

## Epidemic Sound is ready for automation; semantic SFX placement is not

Epidemic is further along than any other SFX source. **Studio, inside the Premiere plugin since December 2025, scans a selection of up to 4 minutes and places a synced draft of music and SFX on the timeline in one click**, with nine alternatives per clip ([Epidemic](https://www.epidemicsound.com/blog/how-to-use-studio)). An AI Assistant that recommends SFX from natural language arrived in April 2026 ([Cision](https://news.cision.com/epidemic-sound/r/epidemic-sound-integrates-ai-assistant-into-plugins-for-adobe-premiere-and-davinci-resolve-studio,c4336355)). Studio targets visual actions (footsteps on a walking person), not essay conventions like whooshes on graphic transitions, and its 4-minute window is short for a 40-minute video. The programmatic route is the **Epidemic MCP server (public beta)**. Claude Code authenticates with an API key from your account, searches a catalogue of 250,000+ SFX, and downloads under your existing subscription, "not a new license" ([Epidemic MCP](https://www.epidemicsound.com/tools/mcp/)). The REST Partner API needs a partnership contract; its free key allows 50 downloads with no commercial licence ([Epidemic developers](https://developers.epidemicsound.com/docs/)). One open question: whether the MCP server saves files to a local path or returns links was not confirmed.

For generation, **ElevenLabs SFX v2 produces 0.1–30 s per call, loops seamlessly (ideal for ambience beds), outputs WAV at 48 kHz and costs 40 credits per second** ([ElevenLabs docs](https://elevenlabs.io/docs/overview/capabilities/sound-effects.md)). Premiere 26.5's Generative Media Tool now generates SFX from text directly in the timeline, sized to the selected range ([Adobe Community](https://community.adobe.com/announcements-732/now-released-generate-sound-effects-and-video-in-the-premiere-timeline-1631426)). Video-to-audio Foley models (HunyuanVideo-Foley, MMAudio) suit live-action B-roll lacking audio more than paper and keyboard cues over stills. Check their licences: MMAudio is reportedly CC-BY-NC ([reeleehq PR](https://github.com/reeleehq/foley/pull/174)). For a personal library, Soundly, BaseHead and Curlo now offer natural-language search and UCS auto-tagging ([Soundly](https://getsoundly.com/); [BaseHead](https://baseheadinc.com/)). The DIY equivalent is CLAP embeddings in a vector index, and a 20-professional user study found CLAP search beat keyword search ([arXiv](https://arxiv.org/pdf/2504.15575)).

What is missing is the decision layer. PremiereCopilot advertises "Auto SFX" (whooshes, impacts, risers), and FireCut syncs whooshes and clicks to its own zoom cuts ([PremiereCopilot](https://www.premierecopilot.com/en); [FireCut blog](https://firecut.ai/blog/3-premiere-pro-plugins-every-editor-needs/)). Both are cut-driven, not meaning-driven. Small open repos show the pattern to copy. ossclip has an LLM place SFX from a described library behind a **deterministic density gate** to prevent overload ([GitHub](https://github.com/AhsanAyaz/ossclip/releases)), and OpenCut-Enhanced places whooshes on cuts and text reveals with ducking ([GitHub](https://github.com/RakibAhmed642/OpenCut-Enhanced)). No published tool reads a documentary transcript and places semantically chosen SFX into Premiere.

## Premiere's automation layer finally makes a custom pipeline cheap

The deciding change since 2024 is that Premiere is now scriptable enough to receive an agent's output precisely. **UXP reached official release in 25.6.** Since then it has gained insert, overwrite and remove actions, in/out points, markers with GUIDs, subclips and transcript calls (including `transcribeClipProjectItem` in 26.5). There is one breaking change to plan around: since 26.3, `create*Action` calls must run inside `lockedAccess` ([Adobe UXP changelog](https://developer.adobe.com/premiere-pro/uxp/changelog/)). On deprecation, Adobe's September 2026 developer post says **CEP stops shipping after December 2029** ([CC Developer forum](https://forums.creativeclouddeveloper.com/t/cep-to-uxp-what-developers-need-to-know/12189)). Claims of a September 2026 ExtendScript cutoff (repeated in OpenCut's README) are unconfirmed and conflict with that post. Community MCP servers already drive the timeline from Claude. **hetpatel-11/Adobe_Premiere_Pro_MCP (about 800 stars, 283 tools, tested on 26.0) includes `set_color_label`, markers, razor and overwrite** ([GitHub](https://github.com/hetpatel-11/Adobe_Premiere_Pro_MCP)). leancoderkavy/premiere-pro-mcp (444 tools, CEP plus a UXP preview bridge) includes colour labels, marker CRUD and ripple edits. It also documents silent failures on some 26.3 installs, and it verifies each edit and reports an error rather than trusting them ([GitHub](https://github.com/leancoderkavy/premiere-pro-mcp)). Adobe's own agents are not there yet. A hands-on review found the April 2026 Adobe connector for Claude works "at Adobe Express level", with no timeline control ([MindStudio](https://www.mindstudio.ai/blog/claude-mcp-adobe-vs-photoshop-premiere-what-it-does)), and the Firefly AI Assistant is a public beta. Offline, FCP7 XML remains the robust hand-off. Premiere also imports OTIO natively, with marker name and colour ([Adobe Community](https://community.adobe.com/announcements-732/now-released-otio-import-and-export-311699)), but users report XML is more reliable.

### What to adopt now and what to build

| Stage | Adopt off the shelf now | Build (the gap) |
|---|---|---|
| Silences, fillers | Premiere Text-Based Editing; FireCut/AutoCut silence passes; auto-editor `--export premiere` as a free alternative | Nothing |
| Retakes | FireCut Remove repetition (English) or AutoCut Repeat (multilingual) as a deleting first pass | **Keep-and-label**: last good take on V1/A1, alternates disabled on V2/A2 or colour-labelled, markers with reasons |
| Generic B-roll | FireCut/AutoCut Storyblocks B-roll, used only for atmosphere | — |
| Cited illustrations | Nothing exists | **Per-paragraph citation harvester and review board, with licence tracking** |
| Blender / maps | blender-mcp; Meshy/Tripo low-poly; GEOlayers templates; Earth Studio | Optional agent that drafts scenes or map comps from paragraphs |
| SFX | Epidemic plugin (Studio plus Assistant); Premiere Generative SFX for one-offs | **Semantic cue planner** resolving to your library, then Epidemic MCP, then ElevenLabs, with a density gate |

The custom pipeline is best assembled as Claude Code skills that write to one intermediate timeline JSON and commit to Premiere at the end:

```
recording.mov + script.md (inline links)
  1. Transcribe   WhisperX (disfluent prompt) -> word timestamps
  2. Derush       auto-editor silence ranges + script-to-transcript LCS alignment (retake-cutter logic)
                  + Claude judgment on paraphrased restarts (OpenRoughCut --ai pattern)
                  -> takes[] {sentence_id, start, end, status: keep|alt|junk, reason}
  3. Harvest      per paragraph: follow cited links (newspaper4k, og:image, srcset, de-resize URLs)
                  + Wikimedia Commons API + SERP image API (DataForSEO/SerpApi; not Google CSE)
                  + yt-dlp ytsearch -> caption timestamp match -> --download-sections
                  + Lens reverse search for HD originals; CLIP/vision-LLM rerank; record licence
                  -> HTML board per paragraph + assets/ folder
  4. SFX plan     Claude reads final transcript + cut list -> cues {t, type, query, dur, gain}
                  rules + density cap -> resolve: CLAP index (personal + downloaded Epidemic)
                  -> Epidemic MCP -> ElevenLabs v2 generation (loops for ambience)
  5. Commit       Option A: emit FCP7 XML / OTIO (keeps V1, alts V2 disabled, B-roll candidates V3+,
                  SFX A4-A6, citation URLs in markers) -> import
                  Option B: Premiere MCP server (hetpatel-11 / leancoderkavy) -> overwrite clips,
                  set_color_label on alternates, add markers; read state back after every write
```

Run steps 2 and 3 in parallel, because the derush needs only the recording and the harvest needs only the script. Treat Option A (XML) as the default and use the MCP server only for what XML cannot carry reliably, chiefly colour labels. That pairing avoids betting on undocumented `<label2>` handling or on beta UXP edge cases. Reuse retake-cutter's alignment rule, OpenRoughCut's XML writer and cut-reason log, broll-fetcher's multi-source search, and ossclip's density gate rather than writing them fresh. Fork each one, given how quickly small repos vanish.

## Conclusion

The market has split along an instructive line. Tools that transform what you said (silences, fillers, repeated phrases) are commoditised at about $15 a month. Tools that need to know what you meant (which citation a paragraph rests on, which sound belongs under a sentence, which alternate take an essayist might want back) do not exist as products. That is not because they are hard to build. Their audience is small, and their legal exposure (scraped agency photos) makes vendors wary. The leverage for a documentary creator is therefore in the script, not the footage. A script that already carries inline links and light cue annotations is a machine-readable edit decision list, and Sima 1.0 shows the approach scales to 1–2 hour films. The second insight is about reversibility. Every shipping derush plugin is destructive, and Resolve's choice to keep alternates on extra tracks is the design to emulate. A pipeline that proposes rather than deletes (labelled alternates, licence-tagged candidates, SFX on their own tracks) is both safer and more useful, because it puts your review time into taste rather than repair. Expect FireCut, AutoCut or Adobe to close the alternate-take gap within a year or so. The citation-harvesting and semantic-SFX layers look likely to stay custom for longer, so they are where custom engineering effort pays off longest.
